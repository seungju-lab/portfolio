## 검증 환경과 범위

Linux 개발 컨테이너의 Chromium 153.0.8010.12, PDF.js 6.3.289, A4·100%·배경 그래픽 켜기를 기준으로 검증했다. 실제 인쇄 창은 Xvfb와 운영체제 키 입력으로 확인했다. 재현 명령과 PDF 페이지별 이미지·텍스트·글꼴 정보는 [구현 검증](full-read-implementation.md#재현)에 연결돼 있다.

배경 그래픽을 끄면 남색이 빠지므로 화면에 켜기 안내를 제공한다. Windows 로컬 Edge/Chrome, Firefox, Safari와 실물 프린터는 검증하지 않았다. 다른 브라우저·설정의 페이지 수까지 12장으로 보장하지 않는다. 이번 Work는 검증 기록과 증거만 추가하며 제품 코드·디자인은 변경하지 않았다.
