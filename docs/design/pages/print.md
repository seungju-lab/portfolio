# 전체 열람과 인쇄

`/print/`는 소개와 세 프로젝트를 한 문서로 읽고 브라우저 인쇄를 여는 화면이다. 웹은 동일한 남색 테마, 중앙 본문 760px과 `홈으로`·`PDF로 저장` 도구 모음을 사용한다. 모바일은 도구 모음과 본문을 단일 열로 배치한다. 인쇄 기능을 사용할 수 없는 환경에서는 브라우저 메뉴의 인쇄 기능을 안내한다.

웹 전체 열람과 PDF는 [상세 문서](project-detail.md)의 세 프로젝트 문단을 모두 유지한다. PDF는 아래 순서의 4장으로 구성한다. 첫 장의 프로젝트 목록은 역할을 요약하고, 각 프로젝트 장에는 상세 본문을 넣는다.

1. 소개와 프로젝트 목록, 교육·활동, 홈서버와 이슈 관리 설계 경험.
2. ILOG: 네 서비스 단독 구현, 인증 경계 정리, OIDC·Host 수정, 확인 결과와 MSA 회고.
3. Lorekeeper: 진행 중 상태, 로그인 양쪽 구현, Work·Episode API, 테스트 작성 범위.
4. Matching SSAFY: 팀 도메인, WebSocket·STOMP 채팅, 연동과 테스트 작성 범위.

종이는 [공통 규칙](../foundations.md)의 print 테마를 사용한다. 프로젝트 이름은 28px, 소제목은 17px, 본문은 14px로 읽는다. 하단에 이름과 페이지 번호를 반복한다. 외부 주소는 확인된 저장소 경로로 표기하며 문장 가운데 잘라 넣지 않는다.

Pencil에는 웹 1440/390px와 A4 네 장을 만든다. 종이 안에서 본문이 끝나고 제목이 본문과 함께 배치되어야 한다. 실제 브라우저 페이지 나눔·링크·한글 폰트 포함은 코드 구현과 PDF 출력에서 별도로 검증한다.

## 도구 모음과 인쇄 반응

이 페이지에는 커서 조명·프로젝트 행 흐림·고정 소제목을 사용하지 않는다. 도구 모음은 문서 흐름 안에 두고, 링크와 버튼의 색·focus는 [공통 컴포넌트](../components.md#textlink와-비조작-요소)를 따른다. 인쇄 버튼은 기본 제목색, hover·focus에서 청록색이며 색에만 공통 전환을 쓴다. 버튼을 누르는 동안 별도 확대·축소는 없다.

| 상황                   | 동작·결과                                                                                                                                                                                             |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 홈으로                 | 같은 탭의 `/`로 이동한다. 브라우저 뒤로 가기로 재진입하면 이전 열람 위치를 복원한다.                                                                                                                  |
| PDF로 저장 실행        | 실제 button을 클릭·Enter·Space·터치로 실행하면 브라우저 인쇄 대화상자를 연다. PDF 저장 위치와 인쇄 대상은 브라우저에서 선택한다. 버튼 옆에 `브라우저 인쇄에서 PDF로 저장할 수 있습니다.`를 표시한다.  |
| 인쇄 대화상자 열림     | 요청한 인쇄가 종료될 때까지 추가 실행을 무시한다. 다운로드 진행률이나 저장 성공 상태를 임의로 표시하지 않는다.                                                                                        |
| 저장·인쇄·취소 후 복귀 | 모두 같은 웹 열람 상태로 돌아온다. 기존 스크롤 위치를 유지하고 인쇄 버튼에 포커스를 복원한다. 대화상자 종료는 파일 저장 성공을 의미하지 않는다. 다시 실행할 수 있어야 한다.                           |
| 호출 불가·실패         | 인쇄 기능이 없거나 호출 오류가 나면 버튼 근처에 `인쇄 창을 열지 못했습니다. 브라우저 메뉴의 인쇄 기능을 이용해 주세요.`를 표시하고 보조 기술에도 알린다. 본문과 홈 이동을 유지하며 재시도를 허용한다. |

인쇄 매체로 전환할 때는 [공통 인쇄 규칙](../foundations.md#인쇄)을 즉시 적용한다. 버튼 실행 여부와 관계없이 브라우저 메뉴·단축키로 인쇄해도 같은 네 장이 나와야 한다. 인쇄가 닫히면 화면 테마를 복원한다. 메뉴·단축키로 시작한 인쇄는 기존 포커스를 유지하고 버튼으로 강제 이동하지 않는다. 이미 페이지를 떠났으면 이전 인쇄 종료 처리로 포커스를 옮기지 않는다.

### 반응 검토 기준

버튼과 브라우저 메뉴 각각으로 인쇄 미리보기를 열고 취소 후 재실행한다. 배경 장식·도구 모음·focus 외곽선이 출력되지 않고 네 장의 본문이 모두 있어야 한다. PDF 저장과 취소 모두 웹의 읽던 위치로 복귀해야 한다. 키보드 Space 실행과 복귀 포커스를 확인하고, 호출 실패 조건에서도 본문을 계속 읽을 수 있어야 한다. 실제 모바일의 인쇄 지원·PDF 출력 결과는 지원 브라우저에서 별도로 확인한다.
