# 공통 시각 규칙

## 색과 글자

레퍼런스의 어두운 배경과 낮은 장식 밀도를 따른다. 색은 텍스트 위계를 만들고, 프로젝트마다 다른 배경색을 배정하지 않는다.

| 역할          | 값        |
| ------------- | --------- |
| 배경          | `#0F172A` |
| 주 제목       | `#E2E8F0` |
| 본문          | `#94A3B8` |
| 보조 문구     | `#8897AF` |
| 링크·태그     | `#5EEAD4` |
| 태그 배경     | `#163337` |
| 행 hover 배경 | `#162238` |
| 구분·목차 선  | `#475569` |

한글은 Noto Sans KR, 영문 직무·기술명·날짜는 Inter를 쓴다. 이름 48/모바일 38px, 직무 20px, 프로젝트 상세 제목 40/모바일 32px, 목록 제목 18px, 본문 16px, 목록 설명 15px, 보조 문구 13px, 태그·목차 12px를 사용한다. 본문 행간은 1.8, 제목은 1.3이다. 한글 제목의 고립된 한 글자 줄바꿈은 허용하지 않는다.

## 구성

1440px 화면의 좌우 여백은 128px, 왼쪽 열 448px, 열 간격 128px, 오른쪽 열 608px다. 상단 여백은 96px다. 홈·상세는 문서 전체가 하나의 스크롤 영역이며 왼쪽 소개에 sticky를 적용한다. 오른쪽 열에 별도 스크롤 영역을 만들지 않는다. 왼쪽 콘텐츠 높이와 위아래 여백 96px씩의 합이 화면 높이를 넘으면 sticky를 해제해 하단 링크까지 읽게 한다. 정적 Pencil에서는 본문 전체를 높이에 맞춰 보여 준다.

1024px 미만에서 단일 열로 전환한다. 390px와 320px에서는 좌우 24px, 상단 48px를 기본으로 하고, 홈은 소개 아래에 가로 목차와 외부 링크를 둔다. 프로젝트 상세는 목차를 숨기고 소개 아래·본문 앞에 외부 링크만 둔다. 프로젝트의 날짜는 제목 위로 이동한다. 문단 간격 20px, 관련 요소 8~16px, 프로젝트 간격 40px, 섹션 간격 80px(모바일 64px)를 기준으로 실제 줄바꿈에 맞춰 조정한다.

## 자산과 상태

프로필 사진은 홈·전체 열람·PDF에 사용한다. 상세·전체 열람·PDF에서는 확인된 시스템 관계를 설명하는 정적 도식을 사용한다. 도식은 실제 서비스 화면 캡처와 구별한다. 상세의 제목 위계·간격·모바일 재배치는 [상세 규칙](pages/project-detail.md#배치와-시각적-위계)을 따른다. 아이콘은 GitHub·이동·문서 열람을 표시하고, 도식의 연결 방향은 선과 화살표로 표현한다.

링크는 청록색 또는 제목+화살표로 표시한다. 목차 선택은 선의 길이와 글자 밝기를 함께 바꾼다. 요소별 기본·hover·focus·선택·해제 상태는 [컴포넌트](components.md#상태와-전환)를 따른다.

## 반응과 움직임

이 절은 웹 반응의 공통 규칙이다. 레퍼런스와 적용 이유는 [개요](overview.md#설계-근거)에 둔다. 문단 등장 애니메이션·패럴랙스·페이지 전체 전환은 추가하지 않는다. 콘텐츠는 처음부터 읽을 수 있어야 한다.

| 공통 항목     | 설계값과 적용 조건                                                                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 짧은 전환     | 지속 150ms, 지연 0ms, `cubic-bezier(.4,0,.2,1)`. 색·행 배경·목차 선·아이콘·행 불투명도에 사용한다. `transition: all` 대신 각 요소에서 지정한 속성만 바꾼다.                                      |
| 중단·반복     | 진입과 해제에 같은 전환을 사용한다. 도중에 상태가 바뀌면 현재 표시값에서 최신 목표로 전환하며 이전 효과를 대기열에 쌓지 않는다. 빠른 왕복 때문에 행 크기·본문 위치가 변하지 않는다.              |
| 포인터 효과   | 1024px 이상이며 `(hover: hover) and (pointer: fine)`인 환경에서만 조명·행 hover·다른 행 흐림을 사용한다. 개별 이벤트가 touch이면 적용하지 않는다. 조건이 해제되면 잔여 hover·조명 상태를 지운다. |
| 키보드        | 모든 크기에서 `focus-visible`에 청록색 2px 외곽선, offset 4px를 즉시 표시한다. 외곽선은 컨테이너에 잘리지 않아야 한다. 키보드로 프로젝트 목록에 들어오면 다른 행 흐림을 해제한다.                |
| 움직임 줄이기 | `prefers-reduced-motion: reduce`에서는 조명을 숨기고 모든 전환·아이콘 이동을 끈다. 배경·색·선택 선은 즉시 최종 상태로 바뀌며 목차 스크롤은 `auto`다. 설정 변경은 새로고침 없이 반영한다.         |
| 스크롤        | 목차 클릭은 브라우저 기본 smooth scroll을 사용한다. 고정 ms를 요구하지 않는다. 수동 스크롤이나 다른 이동 요청이 들어오면 이전 목적지로 되돌아가지 않는다.                                        |

프로젝트의 다른 행은 opacity .9를 적용한다. 가장 옅은 보조 문구 `#8897AF`는 조명의 최대 농도가 배경에 합성된 경우에도 계산상 대비 약 4.66:1이다. 이 계산은 아래 배경 위에 텍스트를 합성하는 조건이며, 구현에서는 조명을 콘텐츠 뒤에 두고 최종 렌더의 대비를 다시 확인한다. 일반 본문·교육·활동에는 흐림 효과를 적용하지 않는다.

## 인쇄

전체 열람의 인쇄는 웹과 같은 남색 배경·청록색 강조·제목색·본문색·태그색과 로컬 글꼴을 쓴다. 사진·도식·텍스트·목차·외부 링크를 보존한다. `print-color-adjust: exact`를 적용하고 실제 브라우저의 배경 그래픽 설정 영향을 확인한다.

A4 모사는 96px/in 기준 794×1123px, 여백 약 60px(16mm)이다. 페이지 바깥 여백까지 남색으로 출력되는지 확인하고 페이지 크기·여백 구현을 조정한다. 글자 크기와 페이지 나눔은 [전체 열람·PDF 명세](pages/print.md#a4-배치)를 따른다. 현재 생성·검증 기준은 8장이며 콘텐츠가 늘어나면 가독성과 페이지 나눔을 재검토한다. 하단 이름·페이지 번호는 본문과 겹치지 않는 보조색으로 표시한다.

인쇄에서는 조명·전환·focus 외곽선·고정 위치·배경 흐림을 해제하고 본문 opacity를 1로 유지한다. 상단의 `홈으로` 링크를 숨긴다. 목차·외부 링크는 실제 PDF 링크로 유지한다. 공통 색은 라이브러리 변수에 연결하고 print의 치수만 매체에 맞게 재정의한다. 아이콘 16/20px·조작 영역 44px·목차 선 1px는 기존 Pencil 변수 해석 문제에 대한 상수 예외를 유지한다.
