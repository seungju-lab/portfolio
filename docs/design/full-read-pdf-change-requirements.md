# 전체 열람·PDF 변경 요구사항

[Deliverable #43](https://github.com/seungju-lab/portfolio/issues/43)의 요구사항이다. 사용자는 전체 열람 페이지의 디자인과 내용을 PDF에도 유지하기를 원한다. 기존 흑백·4장 인쇄 구성은 이 요구사항으로 대체한다.

## 반영 범위

- 전체 열람을 소개·사진·프로젝트 목차, 교육·활동·연락 경로, 세 프로젝트의 개요·아키텍처·문제 해결·결과 순으로 재구성한다.
- 상세 페이지의 도식과 전체 본문을 재사용한다. 담당 범위·진행 상태·검증 한계와 회고를 보존하고, PDF용 요약이나 새로운 성과를 추가하지 않는다.
- 웹과 PDF의 남색·청록색·글꼴·사진·도식을 유지한다. 인쇄 CSS는 A4 배치, 페이지 나눔과 출력에 불필요한 조작 요소 제거를 담당한다.
- 4장 제한을 해제한다. 프로젝트를 한 장에 맞추려고 본문을 삭제하거나 읽기 어려운 크기로 축소하지 않는다.
- PDF의 외부 링크와 내부 프로젝트 목차 이동을 유지한다. 실제 PDF에서 클릭 목적지와 텍스트 선택·검색을 검증한다.
- 대표 프로젝트를 먼저 실제 PDF로 출력한 다음 전체로 확장한다. 최종 출력에 맞춰 문서와 Pencil을 동기화한다.

## 2026-09-15 압축안 채택

사용자가 [Pencil 비교안](pdf-compact-comparison.md)을 저장한 뒤 코드 구현을 요청했다. 전체 본문과 글자 크기를 유지하면서 소개·목차·교육을 첫 장에, 프로젝트 개요와 아키텍처를 같은 장에 묶는 8장안을 구현한다. 아래 Work 목록은 기존 Deliverable #43의 이력이며 이번 후속 구현을 위한 새 이슈를 뜻하지 않는다.

## 수행 순서와 기준

Work #44는 문서, #46은 Pencil, #49는 코드·인쇄 구현, #52는 최종 검증을 담당한다. 각 Work의 하위 Atomic과 실제 검증으로 완료 여부를 판단한다. 구체적인 기준은 [전체 열람·PDF 명세](pages/print.md), 공통 색·글꼴은 [공통 규칙](foundations.md), 본문은 [상세 명세](pages/project-detail.md)를 따른다.

기존 `projects/portfolio` 폴더에서 수행하며 별도 작업 폴더나 worktree를 만들지 않는다. 홈·개별 상세의 현재 기능과 디자인을 유지한다. 이 문서 작성은 Pencil·실제 PDF 검증 완료를 의미하지 않는다.
